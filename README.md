# 🛒 TechBazaar – Electronics E-Commerce Website

TechBazaar is a modern electronics e-commerce website designed to provide users with a smooth and convenient online shopping experience. It showcases a wide range of electronic products, including smartphones, laptops, cameras, gaming devices, audio accessories, smart TVs and wearables.

🌐 **Live Demo:** https://techbazaar-spark-shop.lovable.app/

## 🚀 Features

- **Product Catalog:** Browse a variety of electronic products.
- **Category Filtering:** Explore products by Audio, Cameras, Gaming, Laptops, Smartphones, Tablets, TVs and Wearables.
- **Product Search:** Search for products easily.
- **Product Ratings:** View ratings for listed products.
- **Discount Pricing:** Display product prices and discounted offers.
- **Shopping Cart:** Add products to the cart.
- **Modern UI:** Clean, responsive and user-friendly shopping interface.
- **Authentication Interface:** Login and Sign Up options.

## 💻 Getting Started

To run the project locally:

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project folder:

   ```bash
   cd TechBazaar
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

## 🎯 Project Objective

The main objective of TechBazaar is to develop a user-friendly electronics shopping platform that demonstrates modern frontend development, product browsing, search functionality and e-commerce interface design.
